# M1 Frame, OGV and Divider Wall Geometry Rules (CR-002 option a, CR-003)

Scope: the fan frame (M1.4), the OGV row (M1.3) and the core/bypass divider wall behind the fan. Until CR-002/CR-003
these rules lived only in the code docstrings and the `notes` of `geometry/fan_frame_params.yaml` /
`geometry/ogv_params.yaml`; this file states them, the yaml files hold the ratios. Every length is computed by code
(`geometry/flowpath.py`, `geometry/ogv.py`, `geometry/fan_frame.py`, `geometry/m2_boundary.py`); M2 values are read at
run time from the M2 geometry code and files (read-only import of `engine/M2_booster/geometry/layout.py`, active M2
record), never typed. One tag per rule. Approved changes: CR-002 option (a) and CR-003 (user, 2026-10-30), open
issue #77.

| Id | Rule | Tag |
|---|---|---|
| R-G1.1 | Frame zones: frame length L = `length_over_tip_axial_chord` x rotor tip axial chord. Bypass zone = station 13 plane (OGV trailing edge) to station 13 + L; it holds the outer ring M1.4.2 (aft end) and the bypass struts M1.4.4. Core zone = M2 station 24 plane (S3 trailing edge, M2 R-G2.2, x read from the M2 layout) to station 24 + L; it holds the hub ring M1.4.1 with the M8 bearing flange, the core struts M1.4.5 and the wall ring M1.4.6 (CR-003). The OGV axial position, station 13 x and the outer ring stay where they were. M1 rear end = core zone end. | [T] |
| R-G1.2 | Divider wall ownership: M1 has no splitter ring (former M1.4.3 removed, CR-002 option a). The core/bypass divider wall from station 21 to station 24 is the M2 casing M2.0.2 (owner M2; inner face r_split2 = M2 casing radius, outer face r_root). Behind station 24 the wall is continued by the M1 core wall ring M1.4.6: revolved rectangle r_split2 to r_root, x from station 24 to the core zone end (CR-003). The splitter lip at station 21 (dividing streamline end, M2.0.2 front face) is M2's. | [T] |
| R-G1.3 | Bypass inner radius r_root = r_split2 + M2 casing thickness, the thickness computed from the M2 rule R-G2.12 (`hw_casing_thickness_over_radius` x M2 casing radius) at run time (`m2_boundary.root_radius`); the M2 casing radius must equal r_split2 within 1e-6 m, else the build stops. Station 13 inner radius = r_root; station 13 area = pi (r_tip2^2 - r_root^2); the bypass gas-path inner wall runs (x21, r_split2) -> (x21, r_root) -> (x13, r_root) (`flowpath.yaml` curve `bypass_inner_wall`). | [H] |
| R-G1.4 | OGV span: the OGV M1.3.1 is trimmed to the bypass annulus from r_root (on the M2.0.2 outer face) to the casing wall (r_tip2 + tip clearance); leading edge at x_ogv_le, trailing edge at station 13; sections, count and profile as before (`ogv.py`). | [T] |
| R-G1.5 | Bypass struts M1.4.4: flat plates (chord `strut_chord_over_length` x L centred in the bypass zone, thickness `strut_thickness_over_chord` x chord), trimmed to r_root .. casing wall; their loads land on the M2.0.2 casing outer face (load path not analysed). | [T] |
| R-G1.6 | Outer ring M1.4.2: bypass outer wall at the casing-wall radius from the OGV leading edge to the bypass zone end, thickness `outer_ring_thickness_over_tip_radius` x r_tip1, front flange mating the case rear flange (unchanged by CR-002/003). | [T] |
| R-G1.7 | Core passage in the frame = M2 station 24/25 annulus: hub radius and tip radius from the M2 `flowpath.yaml` interface `M3_station_25` (`r_hub_m`, `r_tip_m`, sha-checked against the M2 record by M2 `layout.record`). The transition duct 24 -> 25 is not modelled (it may need more length, CR-003). | [T] |
| R-G1.8 | Hub ring M1.4.1: core zone, outer face at the R-G1.7 hub radius, thickness = `hub_ring_thickness_over_split_thickness` x t_ref, t_ref = `reference_wall_thickness_over_split_radius` x r_split2; inward bearing flange at the core zone end, thickness `bearing_flange_thickness_over_split_thickness` x t_ref, inner rim = `bearing_flange_inner_over_hub_radius` x station 21 hub radius (M8 boundary radius kept by CR-003; M8 reviews it when M8 starts). | [T] |
| R-G1.9 | Core struts M1.4.5: flat plates, same chord and thickness rule as R-G1.5, centred in the core zone, trimmed to the R-G1.7 annulus (hub radius .. tip radius); same count and angles as the bypass struts. | [T] |
| R-G1.10 | VBV openings: not modelled in M1 (the M1.4.3 placeholder openings left with the splitter ring). They would cut the divider wall, i.e. the M2.0.2 casing (station 21 to 24) or the wall ring M1.4.6 (station 24 to the frame end); owner not set by M0 (#48). | [T] |
| R-G1.11 | Checks: every M1 part valid with volume > 0; common volume 0 among the frame parts, with the OGV row, case, containment ring and rotor (`fan_frame.checks`, `assembly.interference_summary`); OGV and bypass strut smallest radius = r_root within 1e-9 m (`fan_frame.root_radii`); M1 parts vs M2 parts common volume 0 (M2 `hardware.m1_overlap`, read-only, `fan_frame.m2_checks`), OGV, bypass strut and wall ring touch the M2 casing (distance <= 1e-6 m); `m2_boundary` values equal M2 `hardware.build` (`m2_boundary.cross_check`). No constant is tuned to pass a check. | [T] |
