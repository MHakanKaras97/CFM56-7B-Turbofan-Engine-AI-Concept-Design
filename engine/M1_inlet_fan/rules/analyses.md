Notes:
- A-1 status (M1 step 2b, full geometry): design point passes (PR -1.75 %, tip Mrel +1.84 %). Near peak efficiency fails as expected (PR -6.4 %, efficiency -2.8 points): near choke (99 % of 34.96 kg/s), meanline limit; the two outer stream tubes choke at the exit. Strict xfail tests in `tests/test_m1_rotor67.py` record this. Step 2 (unflagged values only) gave PR -1.3 % / -5.8 %.
- A-1 geometry: Z, R, THSP1, THSP2 and edge circles from a clean digital copy of Table I (BladeAtlas, sources #41) [KS]; it agrees with every unflagged OCR value up to OCR digit confusions (1554 of 1774 equal, the other 220 differ only by 3/5, 4/6 or 8/3). TNPC and BETA columns: OCR checked against values computed from the clean coordinates and repaired by digit substitution; 6 values unresolved (unreadable or a garbled row), none used by the model. Visual check against the page images: 27 of 28 LE/TE metal angles agree; section 7 LE is printed 51.41, the code keeps the OCR 51.61 (inside the reference's 0.2 deg accuracy at the edge).
- A-1 endwall blockage: the Table IV stream tube areas are net of the authors' 1.5 % hub and 1.26 % tip blockage (station 2 sum within 0.3 % of the blocked annulus); the model uses them as the flow area, so blockage is included once.
- A-7 bird class (throat area proxy 1.716 m2 [T]): large single 1 x 2.75 kg; large flocking not required (A < 2.50); medium 1 x 1.15 + 4 x 0.70 kg, integrity 1 x 1.15 kg; small 16 x 85 g; core flocking bird 1.15 kg. The medium band edge (1.70 m2) is 0.9 % below the proxy.
- Mirghani 2023 ran a fan blade at 4000 rpm (abstract, p. v) [KS]. Our take-off N1 is about 5282 rpm (Girão 2023 nominal LP speed, M0 `girao_2023.yaml`) [KS]. Centrifugal stress scales with N squared, so Mirghani's stresses are not M1 values; any reuse scales them in code.
- Mirghani's blade is an assumed geometry (Table 4, p. 50): not CFM56-7B data [KS].
